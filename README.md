# UGOT 机器人 Python 课程（七年级零基础）

面向 **13 岁、七年级、零基础** 孩子的优必选（UBTECH）UGOT 机器人 Python 入门课程。
每周一节 **50 分钟理论 + 50 分钟动手**，目标是孩子每周都能带一个能演示的「小场景项目」回家。

> 教学主线：连接机器人 → 用最少的概念让真机器人动/亮/发声 → 三关叠加（MVP 式小项目）→ 进阶挑战。
> 代码全部基于官方核实的 `ugot` SDK，不编造方法名；个别形态专属方法（如车身升降 `transform_*`、机械臂 `mechanical_*`）以占位注释形式给出，需孩子在编辑器里对照 SDK 自动补全确认真实名称。

## 孩子的设备环境（必读）

- 电脑 **ThinkPad X240 + Windows 7**。
- 走**官方在线编辑器**路线（零安装）：
  1. 安装并常驻运行 **uCode Link** 桥接软件（Win v4.4.1）；
  2. 浏览器用 **Chrome / Firefox**（不用 IE / 旧 Edge；Win7 可装 Firefox ESR 115 或 Chrome 109）；
  3. 打开 **https://py.ubtrobot.com** 写代码，点黄色 UGOT 按钮 → Connect to UGOT → 填机器人 IP → Run。
- 电脑与机器人连**同一 WiFi**；机器人 IP 在「设置 → 系统信息（关于）」查看。
- **不要**走 `pip install ugot` 本地装 SDK（Win7 极易装不上），uCode Link 已自带 `ugot` 库。

## 连接机器人的万能开头

每段代码前 3 行（把 IP 换成机器人「关于」里的真实地址）：

```python
from ugot import ugot
ug = ugot.UGOT()
ug.initialize("192.168.x.x")   # 换成机器人真实 IP，且电脑在同一 WiFi
```

更多核实 API（运动 / 屏幕 / 灯光 / 声音 / 传感器 / AI 视觉）见 `UGOT_Python学习指南.md`。

---

## 安全三件事

1. 同 WiFi、空旷场地再跑，先想好急停（`ug.stop_chassis()`）。
2. 干、平整、室内地面最安全；**水 / 冰 / 雪 / 泥 / 沙** 都别去。
3. 别怕报错，报错是老师在说话；改个速度、换个颜色试一试就是调试思维。
